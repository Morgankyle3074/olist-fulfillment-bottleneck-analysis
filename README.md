# olist-fulfillment-bottleneck-analysis

## 📊 Live Dashboard
👉 Tableau Public: [View Interactive Dashboard](https://public.tableau.com/app/profile/kyle.morgan3469/viz/OlistBottleneckAnalysis/Dashboard1?publish=yes)


## 🎯 Business Problem

E-commerce fulfillment performance directly impacts customer satisfaction, operational efficiency, and delivery reliability. 

This project analyzes the Brazilian Olist marketplace dataset to diagnose fulfillment delays, identify operational bottlenecks, and understand the primary drivers of late deliveries.

The key objective of this analysis is to answer:

**What stages of the fulfillment pipeline contribute most to delivery delays?**


## 🛠 Tools & Technologies

• PostgreSQL — Data modeling & analytical views  
• SQL — Metric engineering & feature creation  
• Tableau Public — Interactive dashboard & visual analytics  


## 🔍 Key Insights

✅ **Last-Mile Delivery Dominates Fulfillment Time**  
Cycle time decomposition revealed that last-mile delivery accounts for the largest share of total fulfillment duration.

✅ **Last-Mile Duration Directly Drives Delivery Delays**  
Scatterplot analysis showed a strong positive relationship between last-mile time and delivery delay severity.

✅ **Order Complexity is Not the Primary Delay Driver**  
Contrary to intuition, higher item counts did not consistently produce longer fulfillment cycles.

✅ **Deliveries Exhibit Early Fulfillment Bias**  
Average delivery delay was negative, indicating that many orders were delivered ahead of estimated dates.
